Getting Started

  1. Start the Backend: Run your Flask backend on http://localhost:5000
  2. Serve the Frontend: Open public/index.html in a browser or use a local server
  3. Configure API: Update API_BASE_URL in js/api.js if needed
  4. Start Using: Register a new account or login to access the application

API Endpoints Required

Authentication:
POST /api/auth/login
POST /api/auth/register

User Profile:
GET /api/user/profile
PUT /api/user/profile

Appointments:
POST /api/appointments
GET /api/appointments
DELETE /api/appointments/:id

AI Consultation:
POST /api/ai/ask
GET /api/ai/history

Dashboard:
GET /api/dashboard/stats
