## 🆘 Quick Help

### Common Issues

**Can't login:**
- Backend must have `/api/auth/login` endpoint
- Check API_BASE_URL in js/api.js

**API Connection Error:**
- Verify backend URL
- Check backend is running
- Check CORS headers

**Page not loading:**
- Clear browser cache
- Check console (F12)
- Try different browser

**More help:**
- See [FRONTEND_DEV_GUIDE.md](FRONTEND_DEV_GUIDE.md)
- Check [ARCHITECTURE.md](ARCHITECTURE.md)
