

## 🆘 Troubleshooting

### Issue: Can't login
**Solution**: Make sure backend has `/api/auth/login` endpoint

### Issue: API Connection Error
**Solution**: Check `API_BASE_URL` in `public/js/api.js`

### Issue: Page not loading
**Solution**: Clear cache, check console (F12)

**More help**: See [FRONTEND_DEV_GUIDE.md](FRONTEND_DEV_GUIDE.md)
